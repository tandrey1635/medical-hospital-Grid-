# Лендинг «Medical Hospital»
Верстка лендинга по PSD-макету для медицинской клиники на чистом HTML5/SASS с адаптивной версткой и использованием CSS Grid сетки без Flexbox.

## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


## 🎯 Ключевые функции

### UI/UX элементы
- Плавная навигация по странице
- Адаптивное бургер-меню для мобильных устройств
- Аккордеоны для полезной информации
- Анимированные иконки статистики
- Кнопки с эффектом нажатия
- 3D-эффект переворота карточек врачей при наведении


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки верстки по PSD-макету на чистом HTML5/SASS с адаптивным дизайном и уверенное использование CSS Grid для построения сложных сеток.**
